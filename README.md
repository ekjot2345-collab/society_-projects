# Smart Campus & Student Life

This workspace contains ten standalone React + Vite projects:

```text
pr1/  Smart Campus Navigator
pr2/  Study Space Finder
pr3/  Campus Event Hub
pr4/  Smart Canteen Queue
pr5/  Student Expense Tracker
pr6/  Campus Lost & Found
pr7/  Peer Study Buddy
pr8/  Accessibility Support Portal
pr9/  Assignment & Deadline Planner
pr10/ Campus Shuttle Tracker
```

## Install from the workspace root

```bash
npm install
```

## Run one project

```bash
cd pr1
npm run dev
```

Replace `pr1` with any project folder.

## Build all projects

```bash
npm run build:all
```
